# 编译原理 实验四 目标代码生成

### 231220060 侯兴宇

## 一、程序实现的功能

本程序在实验三中间代码生成的基础上，实现了从 IR 到 MIPS32 汇编的**目标代码生成**。核心包含三个模块：**指令选择**（IR → MIPS 的模板匹配翻译）、**寄存器分配**（基于线性扫描的贪心分配 + 溢出写回）、**栈帧管理**（函数调用约定的完整实现）。

整体流水线：`CMM源码 → 语法/语义分析 → IR生成 → CodeList → generate_target_code() → MIPS汇编(.s)`

---

## 二、指令选择 (Code Selection)

采用直接模板匹配，IR 与 MIPS 指令一一或一对多映射。算术指令按 op2 是否常量选择 `addi` / `sub` 等形式：`ASSIGN` 映射为 `li`/`move`，`PLUS` 为 `addi`/`add`，`MINUS` 统一转为加负数避免 `subi` 兼容性问题，`DIV` 拆为 `div` + `mflo`。内存访问中，`GET_ADDR`（`x := &y`）因预扫描阶段已在栈帧中分配了偏移，直接翻译为 `addi rz, $fp, offset`；`READ_MEM` / `WRITE_MEM` 分别映射 `lw`/`sw`，且 `WRITE_MEM` 两项操作数都走读取接口 Ensure。控制流指令：`GOTO` → `j`，`IF_GOTO` → 根据 relop 选择 `beq`/`bne`/`bgt` 等六种分支，`CALL` → 实参发射 + `jal` + 返回值接收。函数名添加 `func_` 前缀防止与 MIPS 保留指令（`add`、`sub` 等）冲突。`read`/`write` 作为运行时库内联在 `.text` 段，通过 SPIM syscall 实现输入输出与换行。

---

## 三、寄存器分配 (Register Allocation)

寄存器池包含 18 个物理寄存器（`$t0`–`$t9`、`$s0`–`$s7`），每个寄存器记录编号、空闲标志、持有的变量名和脏标记。脏标记设计使仅在被修改过的寄存器溢出时才发射 `sw` 写回，干净数据可丢弃。

**Allocate**（写入操作数）：先查变量是否已在寄存器中（命中复用并标脏），否则找空闲寄存器或触发溢出。**Ensure**（读取操作数）：未命中时从栈帧 `lw` 加载到新寄存器，标记为干净。**常量缓存**：`Ensure` 中专为`OP_CONSTANT` 增加分支，常数以虚拟名 `c_<value>` 参与缓存，循环中反复使用的常量（边界值、步长）第一次 `li` 加载后直接复用。**溢出策略**：18 个寄存器全满时采用轮转贪心法选择牺牲者，`spill_ptr` 保证公平性。**基本块边界冲刷**：`spill_all` 在每个 Label、GOTO、IF_GOTO、CALL、RETURN 前将所有脏寄存器清回内存。这放弃了跨基本块复用，但换来了完整的控制流安全性——任何入口处寄存器池干净，并自动遵守 Caller-Saved 约定。

## 四、栈帧管理 (Stack Frame Management)

变量到栈偏移的映射采用单向链表（`VarDesc`：变量名 + 相对 `$fp` 偏移 + 下一节点），偏移从 0 开始每分配 4 字节递减。`pre_scan_function()` 在函数入口处遍历函数体 IR，收集所有变量和 `DEC` 声明的数组，预先在栈帧中分配偏移（数组按声明大小分配连续空间），实现栈布局与代码发射的解耦。

**Prologue**：`addi $sp, $sp, -8` → `sw $ra` / `sw $fp` → `move $fp, $sp` → `addi $sp, $sp, -N` 分配局部变量。**Epilogue**（RETURN 处）：`move $sp, $fp` → 恢复 `$fp`/`$ra` → `addi $sp, $sp, 8` → `jr $ra`。

**参数传递**：`ARG` 暂存到 `arg_list[]` 缓冲区（逆序收集，CALL 时反转：`arg_list[arg_cnt-1-i]` 为第 i 个参数）。实参发射：前 4 个 → `$a0`–`$a3`，后续压入 `$sp` 下方，返回后回收。形参接收（`PARAM`）：前 4 个从 `$a0`–`$a3` 取，后续从调用者栈帧基于 `$fp` 偏移 `8+(i-4)*4` 定位，存入预分配槽位。

---

## 五、实现亮点

1. **两遍扫描解耦**：`pre_scan_function()` 将栈布局与代码发射彻底分离，添加新 IR 指令类型时只需在预扫描中增补 `check_alloc`。
2. **常量寄存器缓存**：常数以虚拟名参与寄存器缓存，循环中重复使用的常量消除冗余 `li`，不改变分配器核心逻辑。
3. **Caller-Saved 自动保证**：CALL 前的无条件 `spill_all` 以内存为中介自然传递调用者寄存器状态，实现简洁且正确。
4. **安全防护**：函数名 `func_` 前缀防止与 MIPS 保留指令冲突；`strncpy` + 显式置零防止缓冲区溢出；轮转溢出避免寄存器饥饿时反复溢出同一变量。
